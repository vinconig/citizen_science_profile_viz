# Citizen Science Profile Viz

## What is this for?

This repo is for anyone who wants to classify a planned or completed project that uses citizen science, such as project leads, researchers, coordinators and funders.

It works in two steps:

1. **Fill in the questionnaire.** Use the questionnaire (link to be determined) to reflect on your project and define the aspects relevant to its profile.
2. **Visualize the profile.** Once the profile is created following the questionnaire's instructions, use the data viz notebook in this repo to visualize it.

The idea is that the questionnaire and the notebook together become a standardized way of creating a profile for a citizen science project.

## Aspects relevant to all projects

Some aspects can be determined for every citizen science project, whatever its domain.

Of the typologies we looked at, these were identified as the most relevant, and together they give the clearest picture:

- **Wiggins and Crowston [16]:** five project types: *action*, *conservation*, *investigation*, *virtual* and *education*.

## Aspects specific to environmental monitoring campaigns

If your project is an environmental monitoring campaign, there is an additional section. It uses Pocock's two axes:

- **Simple approach → elaborate approach**
- **Systematic monitoring → mass participation**
